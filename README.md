# Calcu-later
A witty calculator that roasts you, makes jokes, and still gets the math right.

Calcu-later is **not your boring calculator**.  
- It solves your math   
- It throws sass, jokes, and witty one-liners 😂  
- Sometimes it challenges you

  
FEATURES
- ➕➖✖️➗ Perform all basic arithmetic operations and also does complex calculations.
- it has two modes - fun mode and challenge mode
- **Fun Mode** – gives back witty responses, jokes, or playful comebacks based on the difficulty level of your question.  
- **Challenge Mode** – asks you a brain-teasing question, you need to answer this question inorder to get the answer to the question that you have asked.  
- Clean and responsive UI with **React + TailwindCSS**.  
- Built with **Vite** for fast development and builds.  

Getting Started  
1. Clone the repository
     git clone https://github.com/AnjanaArjunan/calcu-later.git
3. Install dependencies
    npm install
4. Run the development server
   npm run dev
5. Build for production
   npm run build
6.Preview the production build
   npm run preview

Tech Stack

React – Frontend UI
TailwindCSS – Styling
Vite – Build tool
